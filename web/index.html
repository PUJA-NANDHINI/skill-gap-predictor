AI-Based Skill Gap Predictor

📌 How This System Works

This system analyzes 3 weeks of student performance data across 4 key parameters:

  • Practice Hours – Time spent practicing concepts
  • Assignment Score – Performance in assignments
  • Error Count – Number of mistakes made
  • Quiz Score – Weekly quiz performance

The data is processed using an LSTM deep learning model to predict the future quiz score and identify skill gaps.
